# Content Style — Eternal Flowers

> **Guia de tom, voz, vocabulário e estilo de comunicação.**
> Aplicável a website, Instagram, email, WhatsApp, cartões, embalagens.
> Define como a Eternal Flowers fala — e como NÃO fala.

---

## 1. Tom e Voz

### Personalidade Verbal

A Eternal Flowers fala como a Marina receberia uma amiga no seu atelier:

- **Acolhedora** — como quem diz "entra, senta-te, vou mostrar-te o que estou a fazer"
- **Sábia** — conhece botânica, nomes científicos, o ciclo das flores; partilha esse conhecimento sem arrogância
- **Poética** — usa metáforas naturais, fala de "memórias", "alma", "eternidade", com naturalidade, sem ser piegas
- **Generosa** — ensina, explica, mostra os bastidores, não guarda segredos do processo
- **Portuguesa** — expressões de Portugal (PT-PT), não brasileirismos, não anglicismos desnecessários

### A Voz NÃO é

- Corporativa ("a nossa empresa foi fundada em...")
- Vendedora agressiva ("COMPRE JÁ!" / "ÚLTIMA OPORTUNIDADE!")
- Genérica ("joias artesanais de alta qualidade feitas com amor e carinho")
- Técnica fria ("resina epóxi UV-curing com catalisador...")
- Infantil ("olha que lindinho!")

| peças únicas | produtos / itens / artigos |

| resina (sem adjetivos) | resina epóxi / resina UV |
| atelier | fábrica / oficina |
| memórias com alma | lembranças |
| colheita | apanha |
| desidratação | secagem |
| orquídea [nome científico] | flor roxa / flor bonita |
| transformar | modificar |

### O Poder dos Três Elementos

A marca usa consistentemente uma estrutura tripartida que funciona como fórmula:

> 🌷 Uma flor | 💎 Uma joia | 💖 uma memória eternizada

Este padrão de três elementos deve ser usado noutros contextos:

> **Colheita → Desidratação → Criação**
> **Natureza → Arte → Eternidade**
> **Braga → Lisboa → Mundo**
> **Delicadeza → Beleza → Significado**

## 3. Ritmo e Estrutura dos Textos

### Instagram — Legendas

**Padrão identificado no feed:**

1. **Linha de abertura** — uma frase curta que capta a atenção. Pode ser uma exclamação, um emoji, ou uma afirmação poética. Ex: "✨ Um presente que floresce para sempre."
2. **Corpo** — 2–3 parágrafos curtos (1–2 frases cada). Descreve a peça, a flor, o contexto.
3. **Detalhe do processo** — uma frase sobre o processo: "cuidadosamente desidratadas e eternizadas em resina"
4. **Call to value** — "🌸 Personaliza com a flor que representa a tua história." / "💌 Disponível por encomenda — envia-nos mensagem"
5. **Hashtags** — no final, 5–8 hashtags relevantes

**Exemplo de estrutura (Dia da Mãe, 2025):**
```
✨ Um presente que floresce para sempre.

Estes brincos foram criados com flores reais,
cuidadosamente desidratadas e eternizadas —
tal como o amor de uma mãe.

Neste Dia da Mãe, oferece algo mais do que
um presente.
Oferece uma memória, um gesto, uma peça
única feita com alma.

🌸 Personaliza com a flor que representa a
tua história.

#DiaDaMãe #PresenteEterno #JoiasComHistória
#EternalFlower #BrincosDeFlores #FloresQueFicam
```

### Website — Fichas de Produto

**Nome do produto:** Nome poético + nome da flor
- "Conjunto Blue Orchid" (não "Colar e Brincos de Orquídea Azul")
- "Anel Duplo Flor" (não "Anel com duas flores")
- "Pulseira Trio Floral"
- "Brincos Amor Perfeito"

**Descrição curta:** 1 frase que explica o que é e o que representa.

**Descrição longa:** 2–3 parágrafos:
1. A história da flor (origem, cor, raridade)
2. O processo (como foi eternizada)
3. O significado emocional

## 4. Emojis — Com Moderação

### Permitidos

| Emoji | Contexto |
|---|---|
| 🌺 / 🌸 / 🌷 | Flores, coleções, abertura |
| ✨ | Beleza, magia, eternidade |
| 💎 | Joia, valor, brilho |
| 💖 / 💙 | Memória, emoção, amor |
| 📍 | Localização |
| 🌍 | Envios internacionais |
| 🌿 | Natureza, processo |

### Proibidos

- 😂, 🤣 (não é tom de humor)
- 🔥 (não é marca de hype)
- 💯 (não é marca de street culture)
- 🚀 (não é startup)
- 💰 (não se fala de dinheiro)

### Regra
- Máximo 3 emojis por parágrafo
- Máximo 5 por post/texto
- Os emojis substituem palavras — não são decoração

## 6. Email de Confirmação de Encomenda

**Tom:** Pessoal e acolhedor, como se fosse um bilhete manuscrito.

**Estrutura:**
1. **Assunto:** "A tua joia Eternal Flowers está a ser criada 💖"
2. **Abertura:** "Olá [Nome], obrigada por confiares a tua memória à Eternal Flowers."
3. **O que vem a seguir:** Explicar o processo: a flor vai ser selecionada, desidratada, encapsulada.
4. **Prazo:** "A tua peça ficará pronta em [X] dias úteis."
5. **Cuidados:** "Brevemente enviaremos dicas de como cuidar da tua joia botânica."
6. **Agradecimento pessoal:** "Com carinho, Marina 🌸"
